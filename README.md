# Miha Brešar — academic homepage

A simple, responsive academic website for GitHub Pages, using plain HTML and CSS.

## Edit

- Update biography, research interests and papers in `index.html`.
- Adjust the layout in `styles.css`.
- Replace the portrait at `assets/miha-bresar.jpg` if needed.

No packages or build step are required. Open `index.html` in a browser, or run
`python3 -m http.server 8000 --bind 127.0.0.1` from this directory.

## GitHub Pages

The intended repository is `MihaBresar/mihabresar.github.io`, with public website
address `https://mihabresar.github.io/` once GitHub Pages is enabled.

In the repository's **Settings → Pages**, select **Deploy from a branch**, then
choose the **main** branch and **/ (root)** directory, and save.

## Content sources

The biography, portrait, probability and applied probability interests, email,
and original paper list come from the author's
[previous homepage](https://sites.google.com/view/mihabresar).
Machine learning for finance and AI for mathematics were added at the author's
request. The biography was shortened at the author's request. The four research
interests are displayed with equal weight, without detailed subtopics.

The complete list was checked on 7 October 2026 against the author's public
[Google Scholar profile](https://scholar.google.com/citations?user=mRjFtsEAAAAJ&hl=en),
which lists nine entries: eight papers and the PhD thesis. All eight papers are
included; the thesis is omitted at the author's request.

Paper metadata was also checked against the linked arXiv and publisher records.
The stochastic kinetics preprint uses its revised 2026 arXiv title (Scholar still
displays its original Bessel-driven title). The diffusion copulas paper is labelled
as an ICLR workshop paper, as stated in its arXiv record and manuscript.
Published papers use their current volume and page numbers.
